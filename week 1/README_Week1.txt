WEEK 1 - DATA ACQUISITION, CLEANING AND PREPROCESSING

Files:
1. Week_1_Data_Cleaning_Report.docx - submission report
2. week1_data_cleaning.py - complete Python script
3. requirements_week1.txt - Python packages required
4. README_Week1.txt - project instructions

Run:
    pip install -r requirements_week1.txt
    python week1_data_cleaning.py

The script automatically creates:
    week1_outputs/
        initial_profile.txt
        outlier_summary.csv
        titanic_cleaned.csv
        titanic_model_ready.csv
        missing_values_before_after.png

Dataset:
Titanic public dataset loaded through Seaborn.
