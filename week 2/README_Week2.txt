WEEK 2 - EDA AND VISUALIZATION

1. Install:
   pip install -r requirements_week2.txt

2. Run:
   python week2_eda_visualization.py

3. The script creates:
   week2_outputs/
     descriptive_statistics.csv
     target_distribution.csv
     dataset_profile.csv
     breast_cancer_eda_dataset.csv
     01_target_distribution.png
     02_mean_radius_by_class.png
     03_correlation_heatmap.png
     04_radius_vs_texture.png
     05_mean_area_boxplot.png
     histogram PNG files

Dataset:
Breast Cancer Wisconsin (Diagnostic), a public dataset associated with the
UCI Machine Learning Repository and distributed through scikit-learn.
